## 0.6.5.5.3 · retained application baseline

The last ASCEND working baseline combined independently framed task cards with compact next-step execution. Earlier fixes retained in the subsequent releases include account isolation, guarded encrypted sync, stable language choice, local Privacy lock, recovery/backups, task folding, routine/manual-entry behavior, compact Friends presentation, focus continuity, and request-link lifecycle protection.

This is a concise product history, not a claim that historical tests were all rerun on every subsequent release. The older public source snapshot is **0.6.0.11.3**, not this baseline.

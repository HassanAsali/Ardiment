# Repository scope and historical material

## What is current

The root README and this documentation set describe **Ardiment private beta 0.7.1.1**. The supplied kit updates the repository's public presentation, product/engineering explanation, brand assets, screenshots, recovery guide, and recorded verification scope.

## What is historical

The inspected public repository contained an older source snapshot under:

`ASCEND-v0.6.0.11.3-updated-for-github/ASCEND-v0.6.0.11.3-updated/`

Its package identifies **0.6.0.11.3**. It is not the complete current app and should not be used to infer 0.7.1.1 features or deployment instructions. The previous root README described **0.6.5.5.3**; that documentation version and the included code snapshot were already different.

Older root images (`command-center.png`, `project-map.png`, `progress-intelligence.png`, and `focus-circles.png`) are historical. The current README uses explicitly labeled Ardiment fixture captures in `docs/media`.

This kit preserves historical source/image paths and existing Git history. It does not rewrite archived records, rename compatibility identifiers, or represent old source as a new release.

## What uploading the kit does

- Replaces the root `README.md` and `UPLOAD.md`.
- Adds current reference documents, Arabic instructions, and suggested repository settings.
- Updates existing `docs/assets` illustrations/banners, including old hero animation and stale verification artwork.
- Adds public synthetic-data captures and editable brand assets.

It does not add the full private application, alter secrets, deploy Vercel, run database migrations, rename the GitHub repository, or change its visibility/license settings. The maintainer retains control over whether to publish further source in a separate update.

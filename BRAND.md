# Ardiment · identity reference

## Naming

Use **Ardiment** for the product in interface text, prose, metadata, and Arabic surroundings. Use **ARDIMENT** only for intentional uppercase styling. The former name **ASCEND** appears only in historical context and compatibility explanations.

The final direction retains the familiar nested prism/diamond silhouette and cyan/violet character. It refines an established product rather than presenting an unrelated new app. No meaning, pronunciation, or etymology claim is attached to the name.

Cyan and violet lead the identity. Status colors remain functional accents. Contrast depends on the complete foreground/background pairing, including user-customized themes; a palette alone is not an accessibility certification.

## Typography and interface

The app uses device system typography with Segoe UI, Tahoma, and Arial fallbacks for Arabic. It requires no remote font download. Headings use strong weight; body copy and Arabic line height remain readable. Icons use rounded caps/joins with a consistent approximate 1.8/24 stroke ratio.

Outlined wordmark artwork uses DejaVu Sans Bold. The editable text source and font license are included in [brand assets](brand/). GitHub showcase artwork uses self-contained vector/raster assets instead of relying on custom README CSS or downloaded fonts.

## Logo use

- Preserve aspect ratio; do not stretch or independently recolor nested parts.
- Prefer the mark at 24px or larger; use the dedicated application icon for smaller installation contexts.
- Leave clear space of at least one quarter of the mark's width.
- Use the ink variant on light surfaces and the light/cyan treatment on dark surfaces.
- Wordmark minimum recommended width: 100px.
- Maskable app artwork must stay inside its dedicated safe area; a README logo is not a maskable installation icon.
